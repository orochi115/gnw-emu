# Complete device images

These files preserve the complete original images, including screen content, for the control configuration diagram. They are distinct from the transparent gameplay chassis frames.

- `mario-original.png`: `retro-go-assets/images/official/eu/NSwitch_GameWatch_Legendary_Hardware.png`
- `zelda-original.png`: `retro-go-assets/images/official/eu/NSwitch_GameWatch_TLOZ_Lifestyle_04_image950w.png`

The renderer imports them directly so Vite includes them in development and packaged assets. Source assets are Nintendo product images from the existing asset collection.
