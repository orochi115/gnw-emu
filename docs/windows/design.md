# Windows port design
Use isolated MSYS2 UCRT64 under D:\LLM_Work\Game_Watch\toolchains\msys64 to build the pinned gwemu into native Windows PE binaries. Keep native Node 24 for Electron. Add PowerShell bootstrap/build/package entry points, provenance for .exe outputs, and recursive dependency DLL staging. Install ARM GNU tools for manager and Retro-Go firmware and retain shell scripts usable inside MSYS2.
Desktop frame/QMP remain loopback TCP. Current-session manager requires Windows-specific private discovery and transport rather than POSIX chmod/Unix socket assumptions. Preserve UUID/lease ownership, revocation and source-image isolation. Use existing tests, actual native build, synthetic images and copied stock profiles on Windows; verify saved states, management and packaged application launch. Avoid hardware operations and existing user data.
Alternatives: WSL would build Linux binaries and complicate desktop IPC/deployment; MSVC is unsupported by QEMU and would require a much larger compiler port. UCRT64 follows QEMU's supported MinGW host architecture.
