# 自定义按键

从“编辑 → 自定义按键…”或空闲窗口的同名按钮打开。Mario 和 Zelda 共用一份应用设置；切换示意图不切换配置。设置页使用完整原图，Mario 的 START/SELECT 仍可编辑，但没有引线。

## 按键映射

每个设备按键可以绑定多个键盘键或手柄输入，键盘与手柄同时生效。图标外形区分键盘和手柄，中心文字表示实际按键。每个气泡显示两个映射，箭头翻页，`+` 添加。

- 点击图标后按新键：立即更新当前草稿并停止录制。点击“重新录制”再次更换；“完成”仅关闭详情。
- 图标的 `×`、详情中的“删除”或右键菜单删除当前映射。
- 连发在详情或右键菜单的二级菜单中设置：普通、默认、6/10/15 次/秒。默认频率可在页顶修改。`⚡` 表示按住连发；松开即停止。
- Escape/Tab 默认用于关闭和导航；要录制这两个键，在详情中勾选“录制 Esc / Tab”。

GAME、TIME、PAUSE、POWER、START、SELECT 与方向和 A/B 一样属于普通设备按键。普通映射不要求修饰键，也不录制组合。

## 热键配置

竖直表格列出已有应用和设备动作；每条映射单独设置。组合图标使用 `+` 连接。键盘按下主键并松开整组后结束录制，也可直接切换 Ctrl/Shift/Alt/Meta。手柄组合使用同一设备的多个按钮；摇杆方向只用于普通按键。热键没有连发。

键盘热键要求修饰键完全一致：Shift+A 不会在 Ctrl+Shift+A 下触发。普通 A 在带修饰键时仍有效，因此普通 A 和热键 Shift+A 会标记冲突。两页所有相关映射显示 `!`，详情列出关联动作。冲突只提示，不禁止保存或执行。默认 POWER=O 与加载 ROM=Cmd/Ctrl+O 也会提示重叠。

## 手柄与设备状态

标准手柄默认支持十字键、左摇杆、A/B、Start/Back。非标准手柄可以通过录制按钮或摇杆方向绑定。“设备状态”显示当前接口，提供参与开关、摇杆死区，以及将左摇杆/标准十字键成组添加为方向映射。

如果同一个手柄通过不同驱动上报多个输入，录制会要求选择来源；可关闭重复接口。可识别的接口偏好随配置保存；同名且无法区分的设备参与选择仅在本次连接有效，不持久化连接序号。设备指纹代表浏览器上报的接口，USB/蓝牙或驱动变化可能需要重新绑定。

首次连接或失焦恢复后，按钮/摇杆需要回到中立再接受新按下。断开设备会释放其输入；键盘和其他设备继续有效。

## 保存与输入隔离

页底“保存”才会提交整页草稿；“取消”丢弃映射、连发和设备偏好修改。保存失败会显示错误并保留草稿，可重试。

配置保存在现有 `settings.json` 的 `controls` 字段中，包含版本、bindings、defaultTurboHz 和 devices。它是应用设置，所有 ROM/两种机型共享；保存通过现有串行原子写入保留语言、显示、音频和最近 ROM 等设置。旧设置缺少 controls 时使用默认映射。

打开配置会先停止连发、释放现有输入并等待 QEMU 确认中立，再开始录键。隔离由主进程执行，覆盖键盘、手柄、机身指针和旧输入接口。关闭后仍按住的输入必须先松开再按下，避免刚录制的按键进入游戏。窗口尺寸和时钟显示会恢复，不修改保存的游戏倍率。
