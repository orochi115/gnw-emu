# Interactive photographic chassis implementation plan

**Goal:** Integrate prepared Mario/Zelda chassis with persistent visibility, real pointer controls, aggregate keyboard feedback and UI automation.

**Architecture:** Electron main owns settings and input sources; SessionController publishes desired/applied input snapshots. QEMU/display protocol remains unchanged.
