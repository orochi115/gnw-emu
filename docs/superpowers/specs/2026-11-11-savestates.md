# 即时存档

用户已批准范围：完整 CPU/RAM/外设/虚拟时间和所有 flash 内容；恢复覆盖当前 session；不比较当前 flash 哈希。挂载任何 SD 时拒绝保存和读取；外置 flash 超过 64 MiB 时拒绝。支持无 SD 的原厂与其他固件，但不承诺未知外设。存档格式/尺寸/机型校验仍用于避免错误加载，与比较 flash 内容无关。

QEMU 在 `/machine` 暴露 `save-state` 和 `load-state` 字符串写属性，通过 QMP qom-set 传入绝对文件路径。复用 VMState 完整流，暂停期间保存。所有 guest 可变设备加入 VMState，宿主指针、连接、设置重建或沿用。内置 flash RAMBlock 随流保存；外置原始 flash 显式序列化，解密 XIP 排除并在恢复完成后重建；恢复后 flash 内容写回当前 overlay。恢复失败保留暂停状态，由桌面层回滚此前捕获的恢复点。

桌面保存至 session/states/<版本 UUID>/ 的不可变版本文件夹，并原子更新槽位 manifest 引用；0–9 手动槽位，默认 0。运行中串行操作，保存/读档释放输入并暂停。读档前生成临时恢复点；失败回滚并重新应用当前宿主音量/输入。重复操作、退出/换 ROM 不得与状态操作并行，失败不得破坏已有槽位。

UI：原生菜单添加保存/读取、槽位选择；接入共享可配置热键，默认 F5 保存、F8 读取、F6/F7 前后槽位。底部 toast 展示进度（结束前保留）、成功与槽位切换（3 秒）、SD/容量不支持（5 秒）、失败（手动关闭），不抢焦点，不改变画面尺寸。槽位与时间可在菜单查看。无自动存档、SD 差分或游戏级存档接入。

验证：新状态 API 的拒绝条件；原厂 Mario/Zelda 同进程与跨进程恢复后的 PC/RAM/设备/flash 一致且后续帧可重复；中途 flash 编程/外设事务；重复交叉槽位；失败保留旧槽位并回滚机器；桌面真实菜单/快捷键/toast；typecheck/build、现有原生与桌面回归。
