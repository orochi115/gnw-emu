# README screenshots

Captured from the running macOS Electron application on 2026-11-16 using original Mario/Zelda firmware and isolated temporary user data. No firmware binaries or save data are included here.

- `mario.png`: Mario firmware with the device frame.
- `zelda.png`: Zelda firmware with the device frame.
- `clock.png`: Zelda firmware in desktop clock mode.
- `controls.png`: the visual button-mapping window.

Images are resized for documentation and losslessly encoded as PNG. Device-frame source and processing details are documented in [chassis assets](../../desktop/src/renderer/assets/chassis/README.md).
